# Portfolio - React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite, for a personal portfolio website showcasing skills, projects, and experience as a Software Engineer.

## Features
- **Hero Section**: Animated introduction with profile photo and contact info.
- **Skills & Expertise**: Comprehensive list of technical skills, certifications (with downloadable links), and education.
- **Projects**: Featured projects with GitHub links and live demos.
- **Theme Toggle**: Dark/light mode support.
- **Responsive Design**: Optimized for all devices.
- **Smooth Animations**: Powered by Framer Motion.

## Tech Stack
- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel
